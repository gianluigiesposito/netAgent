# Idea: dai un nome alle reti, assegna i PC alle reti e dichiara quali reti devono
# essere raggiungibili.
NetAgent espande la specifica in piano deterministico.
#
# v2 — Aggiunta segmentazione VLAN con inter-VLAN routing (router-on-a-stick):
#
#   VLAN 10  — LAN_R1_A   (195.100.10.0/24)  — relay verso R1/R2 via IOU1
#   VLAN 20  — LAN_R2_EXT (195.100.20.0/24)  — relay verso R1/R2 via IOU2
#   VLAN 50  — LAN_CISCO_DHCP  (195.100.50.0/24) — DHCP server su IOU1
#   VLAN 60  — LAN_CISCO_DHCP2 (195.100.60.0/24) — DHCP server su IOU2
#
#   IOU1 Ethernet0/1 → trunk dot1Q → Switch1, Switch2
#     .10  gateway VLAN 10
#     .50  gateway VLAN 50  (DHCP server LAN_CISCO_DHCP)
#
#   IOU2 Ethernet0/1 → trunk dot1Q → Switch3, Switch4, Switch5
#     .20  gateway VLAN 20
#     .60  gateway VLAN 60  (DHCP server LAN_CISCO_DHCP2)
#
#   Switch uplink (Ethernet0/0): trunk VLAN 10,50 o 20,60 verso IOU
#   Switch access port (Ethernet0/1..3): access VLAN 50 o 60 per i PC DHCP
# ====================================================================================
